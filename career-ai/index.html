    How these scores are calculated

    This prototype is a transparent rule-based engine (not a trained AI model). Each component is normalized to 0–100, then combined using fixed weights. If you skip a section, its weight is shared out among the sections you did answer, and the result is scaled down by your profile coverage — so an incomplete profile cannot reach a perfect 100.

    • Skills — 40%
    • Interests — 25%
    • Academics — 20%
    • Work preferences — 15%

      About

      What CareerAI is — and what it isn’t

      Why it exists

      Students are often asked to choose a career before they understand what careers actually involve. CareerAI is a structured way to explore: it turns your skills, interests, marks, and work-style preferences into a ranked shortlist you can investigate further.

      How the current prototype works

      The site is now full-stack. A Python FastAPI service backed by SQLite stores the 17 career profiles and runs a transparent rule-based matching engine — not a trained AI model. It compares your profile against career outlines on four axes: skills (40%), interests (25%), academics (20%), and work preferences (15%). Every score on screen can be explained by those rules, skipped sections have their weight shared out, and incomplete profiles are scaled down by coverage.

      What it is not

      Recommendations here support career exploration. They do not predict aptitude, guarantee outcomes, or determine a student’s future. Match scores are indicative profile matches, never probabilities of success. Always talk to teachers, counsellors, and people working in a field before deciding.

      How it is built

      The browser calls the local API for the career catalog, detail views, and recommendations. The same rule engine is mirrored in JavaScript only for an explicit offline demo mode and for automated parity tests. No external AI service or API key is used, and assessment answers are not stored on the server.

      How it can help you

      Use the results as a starting point: open any recommended career, read its roadmap, try a beginner project, and revisit the assessment as your skills grow.
